# CET6 Section C 速记站

一个零依赖的小型 Web App，用来背 CET6 Section C（长篇阅读）历年真题的答案，并练习纯英文测验。前端是原生 HTML/CSS/JS（没有框架、没有构建工具），后端是一个几十行的 Node.js 内置 `http` 服务，用来在多台设备间同步背诵进度。

## 功能

- **背诵模式**：逐篇看中文大意、英文原文大意、每题的中英文题目 + 答案 + 解析，背熟了再进入纯英文测验。
- **纯英文测验**：只给英文题干和选项，答完立刻反馈对错，5 题一结算，超过 80% 正确率会有彩带庆祝动画。
- **直接练习全部题目**：跳过背诵步骤，把题库里所有文章按年份（2016 → 最新）顺序过一遍，每篇文章仍然是完整的 5 道题（不会把不同文章的题混在一起，也不打乱文章内部的题目顺序）。
  - 支持断点续练：中途退出，下次点击会从上次做到的那一篇继续，不会重来。
  - 自动记录错题本：答错的题会被记下来，重新做对会自动从错题本里移除。
  - 每篇单独计时，同时也有整个刷题会话的累计计时。
- **多设备进度同步**：进度存在服务器的 `data/progress.json` 里，多台设备访问同一个地址会自动合并进度（取更靠后的进度、错题取并集、每篇最好成绩和最快用时取较优的一侧），不会互相覆盖。
- **零依赖**：`package.json` 里没有任何 `dependencies`，纯用 Node.js 内置模块和浏览器原生 API 实现。

## 快速开始

```bash
npm run serve
```

默认监听 `0.0.0.0:4173`，终端会打印出局域网内可访问的地址，手机和电脑连同一个 WiFi 就能一起用、进度互通。

```bash
npm test        # 跑单元测试（node:test，同样零依赖）
```

## 数据从哪来

`public/lessons-data.js` 是题库数据（文章原文、题目、答案、解析、中文翻译），由 `scripts/build-lessons.mjs` 从历年 CET6 Section C 真题整理生成。这个仓库里只包含已经生成好的 `lessons-data.js`，原始真题素材没有一起发布；如果想用自己的素材重新生成，需要准备好对应格式的原始数据后运行：

```bash
npm run build:data
```

## 目录结构

```
server.mjs              进度同步的 HTTP 服务（/api/progress）
index.html              页面外壳
public/
  app.js                前端逻辑（状态机 + 渲染，无框架）
  styles.css             样式
  lessons-data.js        题库数据（生成产物）
src/
  parser.mjs             把原始真题文本解析成题库数据结构
  quizState.mjs           测验状态机（答题、计分）
  progressStore.mjs       进度的读写/归一化/多端合并逻辑
scripts/
  build-lessons.mjs       生成 public/lessons-data.js 的脚本
test/                    对应的单元测试
data/                    运行时生成的进度存储目录（不随仓库一起发布）
```

## 说明

这是个人学习用的小工具，纯粹为了自己刷题方便写的，代码风格和取舍都是按这个目标来的，没有考虑做成通用产品。
